## Visual Snapshot

This template uses the same academic design language as the current project deck: deep navy primary tones, red emphasis moments, neutral paper backgrounds, sharp card surfaces, and a clean 16:9 stage. The result should feel like a university presentation that is formal, legible from a distance, and easy to reuse across many academic topics.
